# 梗指南每日学习：新增优先

用户要求：每次学习前先学习主页新增内容，再从原进度继续。

原逻辑仅在持久化队列读空时请求 `nextPage`，主页顶部的新投稿必须等历史分页循环回来才能被发现。

现在每天启动学习，以及未完成任务恢复时，先请求按发布时间倒序的主页第 1 页。以已处理 BV 和现有队列里的 BV 为边界，收集边界之前尚未记录的视频；新增跨页时继续翻页，直到遇到已知 BV 或主页末尾。首次完全没有记录时，用首页初始化队列。

新增条目按主页顺序插到原队列前面，保留原队列的视频、任务 ID 和历史 `nextPage`。同一 BV 只入队一次。先处理新增，再用剩余预算继续原进度；新增用完当天额度时，原进度留到次日。原有每日 10 个视频、3000 秒课程材料及全局预算约束不变。

新增检查每个调度周期最多读取 3 页，未完成时持久化扫描页码与收集结果，下个周期或进程重启后接续；检查完整结束前不抢先学习旧队列。接口失败沿用已有冷却重试与日报机制，扫描结果和旧队列均保留，不将检查失败当作“没有新增”。

恢复中的课程任务交由课程队列调度，避免通用任务队列在新增检查之前先观看昨日旧视频。用户点播任务仍优先；指定失败补学沿用原有独立流程。当天课程已完成后不会因为重启而再开一轮、重复学习或重发日报。

日报增加本轮新增入队数量，实际学习结果仍使用原有条目、图片和投递去重机制。生产部署不改已有学习进度和投递回执。

验证：`node --test test/video-curriculum.test.js test/video-learning-store.test.js test/video-curriculum-retry.test.js test/video-learning.test.js`。
