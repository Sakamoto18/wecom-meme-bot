```powershell

```

## 官方合并聊天记录中的图片

`official_forward.py` 识别官方实际下发的 `[群聊的聊天记录]`、`=== 消息 N ===` 与 `[附件N] 类型:图片 ... URL:` 协议格式，按消息顺序下载图片，并将原文中的附件替换为 `[图片#N]`。发送者和正文位置保留；下载失败的节点写明未读取，不把后一张图误配给前一条消息。只处理当前事件或明确引用所附带的记录，不按普通聊天关键词猜测记录意图，也不主动回捞群历史。

引用合并记录还有另一种已观测格式：`=== 消息 1 ===` 后的 `[消息内容] [群聊的聊天记录]`，其 `[关联消息]` 内用 `--- 第N条 ---` 分隔并缩进附件。2026-11-23 15:14 的失败样本正是此格式，旧解析只接受标题后的 `=== 消息 N ===`，导致 `forward_images=0`。解析现同时支持两种协议节点，将引用封装保留在记录内，用户当前问题不混入协议文字；引用图片通过 `quoted_forward_image_base64s` 传给后端。
