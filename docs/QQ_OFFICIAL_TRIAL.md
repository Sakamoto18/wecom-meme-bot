## 立即使用与退回

管理员从官方后台机器人的“添加二维码”扫码添加好友。私聊 `/指令`、`/usage-report`、图库请求或分享链接。当前已按用户要求清空 `official_trial_groups`：所有已添加官方机器人的群均可 @ 回复，群主授权全量消息后可直接分享，无需逐群登记。填写 OpenID 列表仍可收紧范围；普通 QQ 群号不能直接当 OpenID 使用。最初测试群 **1109147947** 的名称映射保留，仅用于报告显示，不再限制其他群接入。

不满意时仍可直接使用原 NapCat 机器人。彻底关闭官方入口，在服务器 PowerShell 执行：

```powershell
& C:\longtu-qq-bot\scripts\windows\set-official-qq-trial.ps1 -Mode off
```

重新开启用 `-Mode on`。脚本备份配置，只切换 `longtu-official-trial` 与插件的官方开关，再重启 AstrBot；NapCat/Backend/Provider 不重启，但 OneBot 会在 AstrBot 重启期间短暂重连。官方 AppSecret 重置仅影响官方 API，不影响 NapCat QQ 登录或 OneBot Token。

## 已接回的业务

- 共享原 Node 人格、图库、语义选图、链接抓取服务；群/未绑定成员采用 `qqofficial:AppID:kind:OpenID` 命名空间。
- 官方入口不使用模拟真人回复等待，单链接和多链接抓取均跳过人为随机延迟；NapCat 保留原回复与抓取延迟设置。请求仍遵守共享并发限制、缓存、下载/上传超时与失败重试。
- 经用户在已登录会话指定的一次性绑定码核实，配置官方 OpenID 到原 QQ 管理员映射；绑定后 `/指令`、`/add`、`/tag`、`/del`、词族及人格指令继承原权限。绝不按昵称推测身份。
- `/usage-report [YYYY-MM-DD]` 使用原用量查询与图片渲染，在官方管理员私聊回复；不将私人用量报告公开到群里。
- `/crazy-thursday` 及文案增删查转换为原后端请求。
- 官方 ark/msg_elements 卡片中的链接转给原媒体解析器，简介卡片继续复用原渲染。视频先由服务器下载，再走官方上传，避免腾讯访问不到本机媒体 URL；本地文件临时保存，发送结束删除，超过 200MiB 明确拒绝。
- 开启 `official_trial_push_enabled` 后，已绑定管理员的定时用量日报、学习日报/结果同步到官方私聊。官方专属学习目标通过官方平台发送，NapCat 原投递继续保留。
- `official_trial_push_groups` 可配置官方定时群推送目标，但本应用实测没有主动群消息权限，当前保持为空，原 NapCat 继续承担群定时推送。
- 日报通过已核验的 `official_trial_group_bindings` 将官方群 OpenID 映射回普通 QQ 群号，再查询真实群名；查不到时使用配置的名称或群号标签。图片不再展示内部路由字符串，官方来源副标题为“QQ 官方 Bot”。两个入口的用量仍分别统计。

## 图库表情显示尺寸

官方入口的图库表情（后端 `sub_type: 1`）使用官方素材 API 和 Markdown 图片宽高，最长边限制为 200px，按原比例缩小、小图不放大。上传原始文件字节，不裁剪、不拉伸、不重新编码动图；这里只缩小聊天中的显示尺寸，不减少原文件体积。日报、视频简介图和分享图集仍使用普通图片发送，NapCat 保留原表情链路。

素材准备失败时回退普通图片；消息发送结果不确定时不重发，避免重复。发送后删除本次创建的临时素材；官方说明已发消息不受删除影响。清理失败会记录日志，持续失败时需检查平台素材额度。该方式是 Markdown 图片，并非原生收藏表情通道，实际渲染尺寸和动图播放取决于 QQ 客户端。真实素材上传、完成、删除接口已通过，40 项回归通过；客户端显示效果待实际消息验收。

接口依据：[Markdown 图片尺寸](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/type/markdown.html)、[素材上传与删除](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/material-management.html)。

## 分享回执行为

按用户选择，官方入口不发送“收到/解析中/成功”等额外文字；成功时只返回内容。抓取失败、空失败结果、超时、发送失败或内容未全部发出时，最多补一条说明。发送超时只说明结果未确认，不盲目重发。为失败提示预留一条被动回复额度（私聊总上限 4、群聊 5）；图集优先发送原图，超出额度提示未全部发送。NapCat 原贴表情回执不变。

当前官方适配器及公开 API 目录未找到 QQ 群/C2C 的戳一戳发送接口，因此未接入戳一戳，也不通过 NapCat 代替官方身份操作。最终 39 项回归通过，包含成功静默、空失败结果、超时、上传失败及图集回复额度。
