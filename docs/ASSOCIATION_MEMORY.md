# 全局文化联想记忆

文化联想在所有群和私聊共用一份持久记忆，不按群、用户或会话隔离。数据保存在现有梗库 SQLite 的 `taught_association` 表，固定 scope 为 `global`；重启不丢失，也不依赖对话历史。

用户明确教关联，例如“A 不就是 B 吗，你这都关联不起来”，会触发一次有超时限制的结构化提取。保存触发场景、联想对象、对应机制和原话中的触发别名。触发词和目标必须出现在原话中；普通聊天不额外调用提取模型。提取失败时继续正常回复。

召回用当前完整句子匹配已存触发词和别名，最多带入 4 条；在群里学会的关联，另一个用户私聊也可使用。记忆只是文化对应线索，不是事实认证或人格指令。模型自行生成的回复不作为教学写回。旧图片联想库继续保留，并支持纯文字召回。

明确说“别再把 A 联想到 B”会删除这对教学关联，其他对应关系保留。更换关联时可先撤销旧对应，再教新对应。当前撤销需要给出所存触发词和目标，只有“这不对”而不指出两端不会猜测删除。

回复规则不再强制每轮添加抽象联想或攻击性尾巴。已有双关、反差或教学对应时先接住，完成后可以结束；保留角色语气，但不以点评用户表达能力、案例拆解或无关比喻充数。

验证覆盖跨会话召回、数据库重开、中文整句匹配、撤销、无关消息、提取异常和回复路由。测试使用模型替身，真实模型的提取和回复质量仍需部署后验证。

## 将已学梗迁移到新场景

教学记忆只是学习来源之一。视频学习也将机制、适用场景、接法和来源写入全局联想库；已有视频条目无需重学即可以释义和用法参与候选。

回复前增加独立的关系选择：读取最多 48 条已学候选（当前词面命中优先，再补全局教学、联想、视频词条），结合最多 8 条匹配的本地文化语料；只看当前场景与材料，不传人格、历史口癖或角色示例。模型可在没有相同词汇时按因果、角色关系、反差和词义结构选一个梗，也可选 none。返回候选 ID、当前原话锚点、候选原文证据和迁移关系；无效 ID、缺证据、低置信或超时均放弃。

最终回复接收选择结果，角色只负责口吻；关系用于内部理解，不把分析过程说出来，不把原案例的人物事实迁移到当前场景。歌词已命中、正在明确教学、认真求助与摘要任务不额外走这个选择。每个适用回合最多新增一次模型调用，超时 8 秒；空素材无需调用。

候选窗口有上限，尚未实现全库向量检索；模型替身测试能验证跨词面选材链路，不能证明真实模型一定选得好。本地真实模型配置不完整，仍需在部署环境做真实输出评测。
