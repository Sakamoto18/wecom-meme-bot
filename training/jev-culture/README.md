# Jev 文化分析器训练集

这个目录只存放脱敏后的图片语用分析样本，不存 QQ 号、昵称、原始群聊记录或登录态。线上回复仍由 DeepSeek 生成；训练目标是让独立分析器稳定输出结构化的“字面事实 → 语用含义 → 文化证据”结果。

每行一个 JSON 对象，推荐文件名为 `train.jsonl`、`valid.jsonl` 和 `test.jsonl`。样本格式见 `schema.json`。图片使用仓库外的脱敏资源路径或内容哈希，不能把真实 QQ 图片直接提交到仓库。

最小标注要求：

- `input.question`：用户本轮问题；
- `input.vision_summary`：现有视觉模型摘要；
- `target.literal`：像素事实、可见文字和文字主张；
- `target.pragmatic`：主体关系、真正观点、梗机制和立场；
- `target.culture`：文化领域、是否需要检索和具体检索词；
- `target.reply_guidance`：最多两个贴合的联想及其误用风险。

建议第一批准备 240 条：180 条训练、30 条验证、30 条固定测试，并额外维护 20 条高难度挑战样本。历史失败样本和人工构造样本各占一半，至少覆盖拆字/错视、中文网络梗、平台评论截图、长聊天记录、多格漫画、龙图语境和低信息表情包。

训练后的模型必须兼容 Jev 的 JSON 输出协议。若独立模型服务不可用，线上自动退回现有 Jev 路由和 DeepSeek Vision，不影响正常回复。
