# 已校准龙图素材目录

运行 `npm run export:longtu` 会把当前校准索引命中的龙图从企微缓存复制到 `memes/longtu/`。机器人优先读取这个可随仓库部署的目录；目录为空时才回退到本机企微缓存索引。

支持格式：

- `.png`
- `.jpg` / `.jpeg`
- `.gif`

企业微信图片临时素材限制为不超过 10 MB。本项目会忽略空文件和超过 10 MB 的文件。

导出必须通过 `data/longtu-approvals.json` 中的 SHA-256 白名单；评分、排名和排除表只用于生成待审候选，不能让图片自动进入部署素材。导出文件使用 SHA-256 内容哈希命名，生成的 `manifest.json` 是机器人运行时的强制白名单；目录里即使残留未审核图片也不会被选择。
